# Student Portal

A simple C++ student portal project created as part of the Git laboratory assignment.

## Overview

The project demonstrates a basic student-oriented application while practicing Git version control concepts such as commits, branches, merges, file operations, stashing, conflict resolution, and recovery.

## Prerequisites

The project requires a C++ compiler and Git to be installed on the development machine.

A C++17-compatible compiler is recommended for compiling the source code.
